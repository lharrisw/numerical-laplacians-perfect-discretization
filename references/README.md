# References

## Perfect Discretization

The perfect-Laplacian portion of this project was based on:

**Simon Hauswirth.** *Perfect Discretizations of Differential Operators*.  
arXiv:hep-lat/0003007, 2000.

Hauswirth developed the perfect-discretization framework used as the basis for
the perfect-Laplacian portion of my undergraduate thesis.

The MATLAB code in this repository is my own implementation. My implementation
of Hauswirth's perfect-Laplacian construction was exploratory and did not
reproduce his method as faithfully as intended.

The original work is available through arXiv.
